# The Gathering Place — Website

Multi-page site for The Gathering Place (Minneapolis & Saint Paul).
Plain HTML + CSS — no build step. Netlify can deploy this repo as-is.

## Pages
`index.html` · `sundays.html` · `plan-your-visit.html` · `about.html` · `events.html` · `connect.html` · `give.html` · `watch.html` · `contact.html`
Shared styles: `css/styles.css` · Logos: `logo-*.png`, `icon-*.png`

## Editing
Anything in [brackets] or marked "Draft note" is placeholder content awaiting real info
(leadership bios, statement of faith, 501(c)(3) status, photos).
Gathering times/locations should ultimately flow from the Church Center calendar —
see the Events page calendar section.
